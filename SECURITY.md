# Security Policy

## Reporting a Vulnerability

Please use GitHub private vulnerability reporting from the repository's
**Security** tab. Do not open a public issue for a suspected vulnerability,
credential exposure, or bypass of approval, lease, rights, or release gates.

Include a minimal synthetic reproduction, affected revision, expected
invariant, and observed behavior. Do not include real credentials or client
records. The maintainer will acknowledge a complete report as soon as
practical, investigate it privately, and coordinate disclosure after a fix is
available.

## Supported Versions

Until Webup reaches 1.0, security fixes are made on the current `main` branch.
